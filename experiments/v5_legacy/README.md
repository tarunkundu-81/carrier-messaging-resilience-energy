# Earlier Version 5 analyses (archive)

This directory preserves the **separate**, earlier matched-cohort and RCS-failure-proxy ablation scripts and reported CSV files for provenance of the Version 5 comparisons.

- Version 6's uncertainty-aware holdout is generated by `../../run_reti_extended.py` and its results live in `../../results/`.
- These archived analyses use their own previously generated data. They should not be mixed with Version 6's denominators, cohorts, or policy definitions.
- To regenerate the eight-policy matched summary from the preserved input CSV: `cd experiments/v5_legacy && python build_matched_cohort.py`.
- The RCS failure-proxy analysis is a **long-running** synthetic simulation: `cd experiments/v5_legacy && python run_proxy_ablation.py`.

All original outcomes are model-conditional synthetic tests. No operator message trace was used.
