# Choose a license before public release

No software or content license has been selected on behalf of the authors.

GitHub repositories with **no LICENSE file** generally do **not** grant broad reuse permissions. Before publishing or inviting contributions, choose a software license consistent with the ownership and any third-party dependencies, and separately determine appropriate terms for manuscripts and any external datasets.

Examples for consideration include MIT, BSD-3-Clause, or Apache-2.0 for code; choosing among them is an author decision. A code license does not automatically grant rights to distribute third-party event datasets or journal/publisher material.

Use GitHub's license chooser or add a fully reviewed `LICENSE` file when the authors have approved the choice.
