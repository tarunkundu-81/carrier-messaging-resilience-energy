# GitHub and artifact-publication checklist

- [ ] Verify every code result referenced by the final paper matches its declared simulation version and parameters.
- [ ] Confirm generated result CSVs and associated source scripts are preserved in the repository.
- [ ] Re-run the unit test command and at least one end-to-end smoke test.
- [ ] Check no real recipient identifiers, carrier credentials, tokens, or private datasets are committed.
- [ ] Review paper author contact details for publication.
- [ ] Select an approved license (see `LICENSE_SELECTION.md`).
- [ ] Create a **public** GitHub repository named `carrier-messaging-resilience-energy` and push the extracted files.
- [ ] Tag a stable release and mint a persistent archival identifier if required by the manuscript.
- [ ] Update `CITATION.cff` and manuscript with the genuine GitHub/release URL and DOI (do not invent one).
- [ ] Confirm that any third-party datasets added later can legally be redistributed with attribution.
